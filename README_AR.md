# مشروع حاضر لأندرويد (Android WebView)

هذا مشروع مصدر أولي يغلّف تطبيق HTML المحلي داخل تطبيق أندرويد. لا يتطلب اتصالًا بالإنترنت لتشغيل الواجهة أو تخزين بيانات التطبيق محليًا.

## بناء APK باستخدام Android Studio
1. نزّل وثبّت Android Studio على كمبيوتر.
2. فك ضغط `HaderAndroid-Source.zip`.
3. افتح مجلد `HaderAndroid` في Android Studio.
4. انتظر مزامنة Gradle، وثبّت Android SDK المطلوبة إذا طُلب منك.
5. من القائمة اختر **Build > Build APK(s)**.
6. بعد نجاح البناء اختر **Locate** للحصول على ملف APK.
7. انقل APK إلى هاتف أندرويد وافتحه للتثبيت. قد تحتاج للسماح بالتثبيت من هذا المصدر.

## ملاحظات مهمة
- هذا أرشيف مصدر قابل للبناء، وليس ملف APK جاهزًا.
- حفظ البيانات يعتمد على تخزين WebView المحلي. لا تمسح بيانات التطبيق أو تحذفه قبل تصدير نسخة احتياطية.
- روابط واتساب تحتاج الإنترنت، ولا ترسل الرسائل تلقائيًا.
- اختبر النسخ الاحتياطي والاستعادة على جهازك قبل إدخال بيانات مدرسة حقيقية.
